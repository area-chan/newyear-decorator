# Новогодний оформитель

Меню для KDE Plasma, которое включает и выключает новогодние украшения рабочего
стола: снег, гирлянду, ёлку, часы, погоду и пожелание дня.

![Окно программы](docs/screenshot.png)

## Как выглядит стол

![Рабочий стол](docs/desktop.png)

## Что умеет

- шесть украшений в одном окне, каждое можно включить отдельно;
- изменения применяются сразу, перезапускать оболочку не нужно;
- четыре готовых набора: «Полный Новый год», «Уютный минимум», «Только снег»
  и «Выключить всё»;
- обои остаются твоими: снег рисуется поверх текущей картинки, а когда снег и
  гирлянда выключены, возвращается обычный плагин обоев с тем же файлом;
- своя рамка окна, тёмный фон и падающий снег (эффекты рабочего стола должны
  быть включены).

## Что лежит в репозитории

- `main.py` и `winterdecor/` — программа на PyQt5;
- `plasmoids/` — виджеты для стола: погода, часы, ёлка, пожелание дня;
- `wallpapers/org.winter.snow` — плагин обоев со снегом и гирляндой;
- `assets/` — иконка приложения;
- `docs/` — скриншоты.

## Установка

Нужен PyQt5, в Linux Mint он обычно уже стоит:

```
sudo apt install python3-pyqt5
```

Дальше:

```
git clone https://github.com/area-chan/newyear-decorator.git
cd newyear-decorator
./install.sh
```

Скрипт разложит виджеты и плагин обоев в `~/.local/share/plasma`, поставит
ярлык в меню и лаунчер `~/.local/bin/newyear-decorator`.

После установки перезапусти Plasma, чтобы она увидела новые виджеты:

```
kquitapp5 plasmashell && setsid plasmashell >/dev/null 2>&1 &
```

Потом правый клик по столу, «Добавить виджеты»: «Погода», «Часы», «Ёлка»,
«Пожелание дня». Расставь их как удобно и закрепи.

## Как пользоваться

Запустить можно из меню приложений или командой:

```
python3 main.py
```

Переключатели срабатывают сразу, кнопки «Применить» нет. Пресеты выставляют
несколько украшений одним нажатием. Окно таскается за шапку, `Esc` закрывает.

Если выключить всё, обои останутся прежними, просто без украшений.

## Как это работает

У каждого виджета и у плагина обоев есть настройки в конфиге: `enabled` у
виджетов, `Snow` и `Garland` у обоев. Программа меняет их через D-Bus:

```
qdbus org.kde.plasmashell /PlasmaShell org.kde.PlasmaShell.evaluateScript '<js>'
```

Plasma перечитывает конфиг на лету, поэтому `plasmashell` перезапускать не надо.

Снег с гирляндой живут в плагине обоев: он рисует твою картинку и анимацию
поверх неё, клики при этом не перехватывает. Путь к обоям программа берёт из
плагина `org.kde.image` и передаёт его плагину снега.

## Требования

- KDE Plasma 5.24 и новее (проверял на 5.27, Linux Mint 22.3);
- Python 3.10+ и PyQt5;
- `qdbus`;
- включённые эффекты рабочего стола.
